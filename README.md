# Сбор номеров закупок по договорам (zakup.sk.kz)

Статический сайт для GitHub Pages. Серверная часть не нужна.

## Как опубликовать на GitHub
1. Зарегистрируйтесь на github.com и нажмите **New repository**. Назовите, например, `zakup-tool`, тип **Public**.
2. Нажмите **uploading an existing file** и загрузите `index.html` (и этот README). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/zakup-tool/`.

## Как пользоваться
Следуйте шагам на самой странице: установите кнопку-закладку, соберите карточки договоров, вставьте данные и скачайте Excel.

## Важно
- Репозиторий публичный, но в нём нет ваших данных: договоры обрабатываются в браузере.
- Закладка читает текст открытой карточки договора. Если портал изменит вёрстку, её нужно будет поправить.
