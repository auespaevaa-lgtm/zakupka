# Анализ скриншотов договоров (zakup.sk.kz)

Статический сайт для GitHub Pages: загружаете скриншоты карточек договоров и получаете таблицу
«Номер закупки / Наименование поставщика / Сумма договора» с итогом и выгрузкой в Excel.

## Публикация на GitHub
1. На github.com нажмите **New repository**, назовите `zakup-tool`, тип **Public**.
2. Нажмите **uploading an existing file**, загрузите `index.html` и `README.md`, затем **Commit changes**.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/zakup-tool/`.

## Два способа распознавания
**Через Claude API (рекомендуется).** Читает скриншоты так же, как это делал Claude в чате, и ошибается редко.
1. Зайдите на console.anthropic.com, создайте аккаунт и пополните баланс на небольшую сумму.
2. В разделе API Keys создайте ключ и скопируйте его (начинается с `sk-ant-`).
3. Вставьте ключ в поле на сайте. Он сохраняется только в вашем браузере.
4. Рекомендуется задать лимит расходов в настройках аккаунта и пользоваться сайтом только на своём компьютере.

**В браузере без ключа.** Бесплатное распознавание текста (Tesseract). Менее точное: названия поставщиков и цифры
нужно проверять, такие строки помечены «проверить значения». Таблицу можно править вручную.

## Как пользоваться
1. Сделайте скриншоты карточек договоров (должны быть видны «Статус», «Сведения о закупке», «Поставщик»,
   «Общая сумма в тенге», «Ответственный по договору»).
2. Перетащите их на сайт, выберите кнопкой или вставьте из буфера (Ctrl+V).
3. Проверьте таблицу, при необходимости поправьте ячейки, нажмите «Скачать Excel».

Строки, где статус или ответственный не совпадают с условиями отбора, затемняются и не попадают в итог.
